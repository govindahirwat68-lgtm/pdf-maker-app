# PDF Maker App

A simple responsive PDF Maker built with HTML, CSS and JavaScript.

## Features
- Images → PDF (multiple images)
- Text → PDF
- A4 / Letter
- Portrait / Landscape
- Quality selection
- Drag & drop images
- Remove selected images
- Dark mode
- Recent file list (browser localStorage)
- No backend required

## Run
Open `index.html` in a modern browser.

Internet is required on first load because jsPDF is loaded from CDN. For a fully offline version, download jsPDF and change the script reference in `index.html`.
