A colorful 3D-inspired browser PDF workspace built with HTML, CSS and JavaScript.
V4 Features

Drag-and-drop page ordering
A4 / A5 / Letter and portrait / landscape
Page Designer templates
Rich text editor
Merge PDFs
Split/extract pages
Rotate pages
Delete pages
Reorder pages
Text watermark
Page numbers
Optimize/re-save PDFs with object streams
PDF open/preview helper
Dark mode
Local session history
Libraries
pdf-lib 1.17.1 via CDN
jsPDF 2.5.1 via CDN
Run
Open index.html in a modern browser. Internet is required on first load because the PDF libraries are loaded from CDN.
Important
Password encryption is intentionally not advertised as working because pdf-lib does not provide PDF password encryption. A production password feature needs a suitable encryption engine/backend.
